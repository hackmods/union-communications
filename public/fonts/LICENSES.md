# Canvas brand fonts — licenses

Self-hosted for Comms Brand Kit / export canvases only (ADR-014).
No remote font CDN at runtime. All faces below are licensed under the
[SIL Open Font License 1.1](https://scripts.sil.org/OFL).

| Family | Source | Files |
|--------|--------|-------|
| Montserrat | Julieta Ulanovsky et al. | `montserrat/*.woff2` |
| Source Sans 3 | Adobe (Paul D. Hunt) | `source-sans-3/*.woff2` |
| Barlow Condensed | Jeremy Tribby | `barlow-condensed/*.woff2` |
| Oswald | Vernon Adams et al. | `oswald/*.woff2` |
| Source Serif 4 | Adobe (Frank Grießhammer) | `source-serif-4/*.woff2` |
| Roboto Slab | Google / Christian Robertson | `roboto-slab/*.woff2` |

Latin subsets obtained via Fontsource builds (same OFL upstream).
System residual faces (`systemSans`, `systemSerif`) use OS-installed fonts
and are not bundled here.
