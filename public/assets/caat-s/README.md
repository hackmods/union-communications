Brand tokens from the art: primary `#EA5A4F`, accent `#FFB837`.

SVG files share a single artboard (`viewBox="0 0 174 97"` with matching
`width`/`height`). Plated variants (`on-primary`, `on-gold`, `reverse`) draw a
colour `<rect>` that covers that viewBox so downloads match the Brand Assets
preview. Transparent variants stay plate-free. Keep crops tight when replacing
assets so Look cards stay OPSEU-tight in the UI.
