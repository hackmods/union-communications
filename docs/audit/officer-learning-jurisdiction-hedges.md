# Officer Learning — jurisdiction hedges (Ontario multi-union)

**Audience:** agents + authors writing or reviewing OL modules.  
**Not** steward-facing copy. Do not paste this file into public UI.  
**Companion:** [`session-knowledge-2026-09-06-officer-learning-system-uplift.md`](session-knowledge-2026-09-06-officer-learning-system-uplift.md)

When you need precision that ages badly, **hedge and point to counsel / national constitution / local bylaws** instead of inventing numbers or union-specific clause names.

---

## Hard hedges (keep these honest)

| Topic | Teach | Do **not** invent |
|-------|-------|-------------------|
| **LRA mid-term strike (M7)** | Ontario labour law treats many concerted mid-term withdrawals (OT bans, slowdowns) as strike activity that can be illegal during the term of a CA | Exact OLRB remedies, fine amounts, or “always legal if you call it work-to-rule” |
| **Rand vs card (M11)** | Dues deduction ≠ voting membership; signed-card + good standing rules come from constitution/bylaws | “Automatic member” as correct answer; one national “Membership List Directive” clause number as universal law |
| **T4A / honoraria (M12)** | Honoraria are generally taxable; locals must follow CRA reporting | Hardcoded dollar thresholds that go stale |
| **Without prejudice vs precedent (M8)** | Prejudice ≈ exploratory talks without admission; Precedent ≈ signed deal does not bind unrelated future cases | Swapping the labels in quiz prompt ↔ explanation |
| **OHSA / LSST + JHSC (M10)** | JHSC recommendations often trigger a written employer response clock (commonly cited as 21 days) | Treating LMC as having the same statutory teeth unless the CA says so |
| **Universal Quorum Scale (M4)** | Teaching default for practice quizzes | Claiming every local’s bylaws match 5%/10 tiers — always confirm governing documents |
| **DFR (M15)** | Fair representation duty is real; stewards investigate, communicate, meet clocks | “Not a lawyer” as a free pass to ignore members; inventing OLRB filing windows |
| **Seniority / bumping (M16)** | CA language + past practice + bargaining-unit scope control bumping | Hardcoding one college sector formula as Ontario-wide law |

## Voice

- Multi-union Ontario: CUPE / Unifor / CLC / OHRC as **education sources**, never OPSEU/CAAT as the default tenant in core prose.
- French: claim parity with EN (especially LRA↔LRT, OHSA↔LSST, JHSC↔CSTS, Without Prejudice↔Sans préjudice).
- Warnings: name **consequence + remedy**.
